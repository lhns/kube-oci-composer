{{ if not .Values.operator.servingHost -}}
WARNING: operator.servingHost is not set.

Only ImageCompositions with spec.push will reconcile. Anything relying on the built-in serving
endpoint will report a terminal error, because there is no host to build status.artifact.ref from.
{{- else -}}
Artifacts will be served as:

    {{ .Values.operator.servingHost }}/<publish.name>:<publish.tag>

REFERENCE A DIGEST, NEVER THE TAG. The tag moves; a workload pinned to it plus
pullPolicy: IfNotPresent will silently keep stale bytes. Each build also publishes an immutable
<tag>-<digest[:12]> that is safe to pin by hand, or let Flux image-automation write the digest
into git. See docs/adr/0010.
{{- end }}

Check on it with:

    kubectl get imagecomposition -A

{{ if not .Values.operator.s3.endpoint -}}
The layer cache is local to this pod, so a restart or a reschedule re-fetches every layer from
upstream before the endpoint can serve anything. Set operator.s3.endpoint to keep it across both.
{{- end }}
{{ if eq (int .Values.operator.gc.keepBuilds) 0 -}}
gc.keepBuilds is 0, which will be clamped to 1. Only the newest build stays pullable, so reverting
a commit or rescheduling a pod pinned to an older digest will fail.
{{- end }}
